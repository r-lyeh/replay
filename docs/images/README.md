# images

Small pictures of Replay along the way, for [README.md](../README.md),
[HELP.md](../HELP.md) and the rest of the docs.

- Square, 1:1: a crop of a screenshot (320 x 320 px), never scaled.
- PNG, named after what they show (`graph.png`, `atlas.png`).
- In a page: `![what it shows](images/graph.png)`, or
  `<img src="images/graph.png" width="160px"/>` to show it smaller.

| File | Shows |
|---|---|
| ![](game.png) | `game.png`: asteroids, playing inside the editor |
| ![](editor.png) | `editor.png`: the toolbar and the world's tree |
| ![](graph.png) | `graph.png`: a system as a node graph |
| ![](atlas.png) | `atlas.png`: the atlas packer, a sheet with one image selected |
| ![](lcd.png) | `lcd.png`: Parcels (games/lcd), an LCD game drawn from a cut atlas |
